# Livewire Flux Pro v2.15.0

The pro version of [Flux](https://fluxui.dev), the official UI component library for [Livewire](https://livewire.laravel.com).

## Requirements

- PHP ^8.1
- Laravel ^10.0 | ^11.0 | ^12.0 | ^13.0
- Livewire ^3.7.4 | ^4.0

## Installation

```bash
composer require livewire/flux-pro
```

After installation, the package will automatically register its service provider.

## Usage

Flux Pro extends the core Flux components with additional pro features and components.
